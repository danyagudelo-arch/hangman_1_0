## 3. Estructura del proyecto

El proyecto estará organizado en tres archivos principales:

- `hangman.py`: contiene la lógica principal del juego.
- `palabras.py`: contiene la lista de palabras disponibles.
- `ahorcado.py`: contiene los dibujos de las etapas del ahorcado.

## 4. Requisitos para ejecutar el programa

- Tener Python instalado.
- Tener Visual Studio Code o una terminal disponible.
- Descargar o clonar este repositorio.

## 5. Ejecución del programa

Desde la terminal, ubicarse dentro de la carpeta del proyecto y ejecutar:

```bash
python hangman.py
```
